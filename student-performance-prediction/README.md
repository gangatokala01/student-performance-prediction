# 🎓 AI-Powered Student Performance Prediction & Analytics System

## 📌 Project Overview

This project is an AI-powered student performance prediction system that uses Machine Learning to predict a student's final score based on academic and lifestyle factors.

The system takes inputs such as study hours, attendance, previous score, assignment score, and sleep hours and predicts the student's expected final score.

## 🚀 Features

- 📊 Student performance data analysis
- 📈 Data visualization
- 🤖 Machine Learning prediction
- 🎯 Final score prediction
- 🏆 Performance category
- 🖥️ Interactive Streamlit web application

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Git & GitHub

## 🤖 Machine Learning Model

The project uses **Linear Regression** to predict the student's final score.

### Input Features

- Study Hours
- Attendance
- Previous Score
- Assignments Score
- Sleep Hours

### Target

- Final Score
